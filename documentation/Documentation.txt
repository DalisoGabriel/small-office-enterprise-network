1. Project Overview

Project Name: Small Office Enterprise Network

Platform: Cisco Packet Tracer

Project Type: Enterprise Networking / Network Infrastructure

Objective:

Design and implement a small enterprise network that provides departmental segmentation, centralized DHCP services, controlled access to server resources, and connectivity to an external network.

2. Requirements

- Three departmental networks
- A dedicated Server VLAN
- DHCP addressing for client PCs
- Inter-VLAN communication
- Controlled access to server resources
- Internet/external network connectivity
- Network address translation

4. VLAN Configuration:

VLANs were implemented to logically separate departments into different broadcast domains and improve network organization and security.

5. Router-on-a-Stick

Because multiple VLANs need to communicate, a router-on-a-stick configuration was implemented using 802.1Q subinterfaces.

6. DHCP

A centralized DHCP server was placed in VLAN 40. DHCP relay was configured on the router's client VLAN interfaces so that DHCP broadcasts could reach the server across VLAN boundaries.

7. ACL / Security

Security requirement

HR users should not have access to resources located in the Server VLAN, while Sales and IT should retain access.

8. NAT/PAT

NAT/PAT was implemented to allow private IPv4 addresses used by internal VLANs to access a simulated external network through a single WAN address.

10. Lessons Learned

Lessons Learned:

- VLANs provide logical network segmentation.
- Trunking allows multiple VLANs to traverse a single physical link.
- Router-on-a-Stick enables inter-VLAN routing.
- DHCP relay allows a centralized DHCP server to serve multiple VLANs.
- Extended ACLs can control traffic based on source and destination networks.
- NAT/PAT allows private networks to communicate with external networks.
- Troubleshooting requires testing each layer systematically.

11. Future Improvements

Future improvements could include implementing redundant switches/routers, dynamic routing, wireless networking, additional security controls, and centralized network monitoring.
